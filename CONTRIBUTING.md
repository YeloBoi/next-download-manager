# Contributions

External code contributions are not accepted under unconditional open-source
terms. The owner must finalize contributor permissions and any required agreement
before accepting patches. Bug reports without private data are welcome after a
repository reporting channel is established.

Use small changes and local HTTP fixtures for networking tests. Do not depend on
public download sites. Checks and builds run on GitHub Actions at the owner's
request; do not install dependencies or build on the owner's machine.
